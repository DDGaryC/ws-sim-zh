# 對戰提示文字翻譯：子代理工作指示

你要把 Weiss Schwarz 模擬器對戰中跳出來的英文提示（卡片腳本裡的問題、訊息、選擇角色的說明、選項）翻成繁體中文（台灣用語）。

1. 先完整讀過用語表：`card_text\用語表.md`，區域、關鍵字、能力名稱都照它（例：stock → 能量區、clock → 傷害區、waiting room → 休息室、memory → 思出區、level → 等級區（指區域時）、climax → 名場面、soul → 魂、power → 戰力、battle opponent → 戰鬥對手、front row/center stage → 前列、back row/back stage → 後列）。
2. 輸入檔是 `card_text\{批號}_src.txt`，每行「編號<Tab>英文」。每一條都要翻，不可略過。

翻譯重點：
- 這些是對話框裡給玩家看的句子，要簡短自然。問句結尾用「？」，例：「Draw a card?」→「要抽 1 張卡嗎？」、「Use the effect?」→「要使用效果嗎？」。
- 「Choose a character to give +1000 power.」這類 → 「請選擇 1 張角色，給予戰力 +1000。」
- 卡名（英文 "..." 括起來的）保留英文，改用「」。特徵 `<XXX>` 或 «XXX» → 《XXX》（保留英文）。
- 有些是卡片台詞或人物說話（例：「Jake: What Was Missing returns from memory.」），人名、卡名保留英文，其餘照意思翻。
- 「Effect 1」「Option A」這類短標籤也要翻（「效果 1」「選項 A」）。
- 文字裡的 X、{0} 之類的佔位符、`<sprite .../>`、`<b>` 等標籤原樣保留。字面的 `\n` 照原樣保留。
- 數字和中文之間留一個空格；& 寫成全形 ＆。
- 意思必須和英文一致，不可增減數量、對象（你的／對手的）。英文文法有小錯時照合理意思翻。

輸出：用 Write 工具寫成 `card_text\{批號}_part.json`，格式 `[{"i": 0, "zh": "..."}, ...]`，依編號排序，JSON 字串裡的雙引號要跳脫。

寫完要自我檢查：用 python 讀回（PYTHONIOENCODING=utf-8；檢查腳本寫成 .py 檔再執行，不要用 bash heredoc），確認筆數正確、編號齊全、每筆的 sprite／b／i 標籤和英文一致。不符就修正。

最後只回報：完成筆數，以及真正需要人工確認的條目（編號＋一句原因）。沒有就說沒有。
