0. 安裝模擬器
--------------------------------------------------------------------------
不要使用你過去安裝舊版模擬器的任何資料夾。
請使用一個新的空資料夾。

1. 下載 Weiss-Sim-(版本).zip 和 CardContent-(日期).zip 兩個檔案。
2. 解壓縮 Weiss-Sim-(版本).zip。
3. 依照下方 (A.) 的步驟操作。

A. 安裝初始卡片資料
--------------------------------------------------------------------------
1. 下載 CardContent ZIP 檔（通常和本程式放在同一個 Google Drive 資料夾）。
2. 把「CardContent」資料夾解壓縮到「Weiss Schwarz.exe」所在的同一層資料夾。
   建議用 7-Zip 解壓縮，Windows 內建的解壓縮工具慢很多。
   資料夾結構應該如下：
     - Weiss Schwarz.exe
     - CardContent
     - ……（模擬器需要的其他資料夾和檔案）
3. 啟動模擬器。
4. 進入「設定」，按「Update Cards（更新卡片）」。這會檢查你的安裝，確保所有玩家都有最新的卡片資料。
   視需要下載的新系列數量，可能要花一些時間，不過步驟 1 下載的 CardContent ZIP 應該已包含大部分內容。

B. 音效與背景音樂（SFX & BGM）
--------------------------------------------------------------------------
所有音效和背景音樂都可以透過 ./Audio 資料夾自行設定與開關。
JSON 檔的格式很簡單，只要替換檔案、改檔名，就能建立你自己的音效和背景音樂庫。
對戰中的 BGM 是「分段式」的，類似遊戲王 Master Duel：
  第一首在等級 0 時播放，第二首在等級 1 和 2 時播放，第三首在等級 3（如果是 MKI 的話還有更高等級）時播放。

C. 模擬器更新
--------------------------------------------------------------------------
模擬器現在附帶一個小型更新程式來協助內部更新，它做的事情其實就是自動執行 (D.) 的流程。
當模擬器偵測到有新版本時，會詢問你是否要更新。
如果你同意，更新程式會啟動、下載新版本、關閉遊戲、進行更新，然後重新啟動遊戲。

D. 模擬器更新（手動）
--------------------------------------------------------------------------
./CardContent、./Decks、./Audio 資料夾現在不受模擬器本體管理，所以你可以單獨更新程式本身。
最乾淨的更新方式如下：

1. 下載最新版本。可以對照 Google Drive 上的 README.txt 確認版本。
2. 從模擬器的解壓縮位置刪除以下檔案和資料夾：
   - ./MonoBleedingEdge
   - ./Weiss Schwarz_Data
   - ./README.txt
   - ./steam_appid.txt
   - ./UnityCrashHandler64.exe
   - ./UnityPlayer.dll
   - ./Weiss Schwarz.exe
   注意：也就是安裝資料夾中「除了以下項目以外」的所有東西：
   - ./Audio
   - ./CardContent
   - ./Decks
   - ./GameLogs
3. 把新版模擬器的 ZIP 解壓縮到這個資料夾，和現有的 ./CardContent、./Decks、./Audio 放在一起。
   完成後的資料夾結構應該和之前完全一樣。
4. 正常啟動遊戲，確認主選單右上角的版本號碼。

（中文化補充：請一律用「Weiss Schwarz 中文版」或「Weiss Schwarz (Patch and Run)」捷徑啟動。
  模擬器更新後，捷徑會自動重新安裝翻譯插件。更新程式自己重開的那一次會是英文，關掉再用捷徑開即可。）

附錄：如何更換音樂（額外補充，不在原文中）
==========================================================================
【最簡單：用「音樂設定工具」】雙擊桌面或模擬器資料夾裡的「音樂設定工具」捷徑，就能在圖形介面選電腦上的音樂、看波形試聽、直接在波形上拖曳選出循環範圍，按「儲存」即可。以下是手動修改的方法。

所有音樂設定都在 ./Audio/audio_catalog.json（用記事本打開即可編輯），音樂檔放在 ./Audio/BGM。
修改前建議先備份 audio_catalog.json。支援的格式：.mp3、.wav、.ogg。

【方法一：最簡單——直接替換檔案】
把你想要的歌改成跟原本一樣的檔名，覆蓋 ./Audio/BGM 裡的檔案即可。例如：
  - DeckEditorTheme.mp3　→ 牌組編輯器的音樂
  - BGM_1_1.mp3 ~ BGM_7_3.mp3 → 對戰音樂（見下方說明）
注意：原本的循環點設定（loopPoints）是針對原曲設的，換歌後請參考方法三修改或刪除對應的循環點，
否則新歌可能會在奇怪的位置跳回去重播。

【對戰音樂的運作方式】
"duel_stepped" 裡有 7 組 fileSets，每場對戰開始時會「隨機選一組」，每組有 3 首：
  - track1：等級 0 時播放
  - track2：等級 1～2 時播放
  - track3：等級 3 以上時播放
每組都必須填滿 track1、track2、track3 三首，否則那一組會被忽略。
如果想讓三個階段都放同一首歌，三個欄位填同一個檔案即可。

【方法二：新增或刪除對戰音樂組】
在 "fileSets" 裡加入一組（注意逗號）：
    {
        "track1": "BGM/我的歌_平靜.mp3",
        "track2": "BGM/我的歌_緊張.mp3",
        "track3": "BGM/我的歌_決戰.mp3"
    }
想只聽自己的歌，就把其他組刪掉，只留下自己的。

【方法三：循環點（loopPoints）】
"loopPoints" 設定每首歌播到哪裡要跳回哪裡，達到無縫循環：
    {
        "track": "BGM/我的歌_平靜.mp3",
        "loopStart": "0:15",       ← 跳回的位置（分:秒，可寫到毫秒如 0:15.250）
        "loopEnd": "2:40",         ← 播到這裡就跳回 loopStart
        "crossfade": true,         ← 跳回時是否淡入淡出
        "crossfadeSeconds": 1.5    ← 淡入淡出秒數
    }
沒有設定循環點的歌，會整首播完再從頭重播。
loopEnd 必須大於 loopStart，否則會被忽略。

【音量】
每個項目的 "volume" 是音量（0.0～1.0），也可以在遊戲主選單的「Audio」畫面用滑桿調整後按「保存」。

【音效】
音效檔在 ./Audio/SFX，同樣可以用同檔名覆蓋來替換，或在 audio_catalog.json 對應項目的 "files" 裡
放多個檔案（遊戲會隨機挑一個播放）。

【快取】
遊戲第一次播放 .mp3 時，會把它解碼成 .wav 存到 ./Audio/AudioDecode。
換了檔案後遊戲會自動偵測並重新解碼，一般不需要手動處理；如果聲音沒有更新，
可以把 ./Audio/AudioDecode 資料夾刪掉，遊戲會重新產生。

【備份提醒】
./Audio 資料夾不會被模擬器更新覆蓋，你的自訂音樂在更新後會保留。
