# 卡片效果翻譯用語表（繁體中文・台灣用語）

翻譯目標：讓台灣玩家一看就懂，用語和中文化介面一致。規則意思必須和英文完全相同，不可增刪條件。

## 格式規則
- `<sprite name="..."/>` 標籤**原封不動保留**，位置照英文語序放在對應詞語旁。
- 卡名（英文裡用 "..." 括起來的）**保留英文原名**，改用「」括起來，例如 "Class Clown, Anis" → 「Class Clown, Anis」。卡名裡本身有引號的照原樣保留。
- 特徵 `<NIKKE>` → 《NIKKE》（保留英文）。
- 數字、+3000、-1、×1000 照原樣。
- 能力開頭：`Auto:` → 【自】、`Cont:` → 【永】、`Act:` → 【起】。能力裡引號中的能力（"Auto: ..."）也一樣轉換，外層用「」。
- 費用的方括號 `[...]` 保留成 `[...]`，裡面照翻。
- 句子用全形標點（，。：「」），數字和中文之間留一個空格（例如「最多 1 張」），費用括號 ] 後面不留空格。
