# 卡片效果翻譯：子代理工作指示

你要把 Weiss Schwarz 卡片的英文效果文字翻成繁體中文（台灣用語）。

1. 先完整讀過用語表：`card_text\用語表.md`，嚴格遵守（區域、關鍵字、判定圖示名稱、句型、格式）。
2. 參考已翻好的譯文掌握風格：`card_text\NIK_tw.json`（{英文: 中文}），先看 40 條左右。
3. 輸入檔是 `card_text\{批號}_src.txt`，每行「編號<Tab>英文」。每一條都要翻，不可略過。

格式重點：
- `<sprite name="..."/>`、`<b>`、`</b>`、`<i>`、`</i>` 標籤原樣保留，數量和種類必須和英文完全一樣。
- 卡名（英文裡 "..." 括起來的）保留英文，改用「」；卡名本身有引號的照原樣保留在「」裡。
- 特徵 `<XXX>` → 《XXX》（保留英文）。
- 能力開頭：Auto: → 【自】、Cont: → 【永】、Act: → 【起】；CxCombo → 【名場面連動】；BRAINSTORM → 【集中】、ENCORE → 【再演】、BACKUP → 【助太刀】、ASSIST → 【應援】等（見用語表）。
- 數字和中文之間留一個空格（「最多 1 張」「戰力 +3000」）；費用括號 ] 後面不留空格；& 寫成全形 ＆。
- 判定圖示開頭的句子（`<sprite name="mini_xxx"/> When this card is triggered, ...`）開頭不加【自】，翻成「這張卡判定時，……」。
- 規則意思必須和英文完全一致，不可增減條件、次數、數量、對象（你的／對手的）。英文文法有小問題時照合理意思翻。
- 英文裡的字面 `\n`（反斜線加 n）照原樣保留。

輸出：用 Write 工具寫成 `card_text\{批號}_part.json`，格式 `[{"i": 0, "zh": "..."}, ...]`，依編號排序，JSON 字串裡的雙引號要跳脫。

寫完要自我檢查：用 python 讀回（PYTHONIOENCODING=utf-8；檢查腳本寫成 .py 檔再執行，不要用 bash heredoc，以免反斜線被吃掉），確認筆數正確、編號齊全、每筆的 sprite／b／i 標籤和英文一致。不符就修正。

最後只回報：完成筆數，以及真正需要人工確認的條目（編號＋一句原因）。沒有就說沒有。
